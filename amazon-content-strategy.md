**Логика недели:**
- **Пн** — открываем неделю провокацией / сравнением → максимальный reach
- **Вт** — история с деталями → вовлечение и доверие
- **Ср** — визуальный контент с цифрами → сохранения
- **Чт/Пт** — работа с возражениями → лиды (смотрят те кто уже думает о переходе)
- **Сб** — мышление/манифест → идентичность и подписка
- **Вс** — триггер недели → виральный spike на актуальной новости

## Механики виральности

### Триггеры сохранений (самый важный сигнал алгоритма)
- Таблицы цифр — «сохраню, потом посчитаю»
- Конкретные инструменты и шаги — «сохраню, чтобы воспользоваться»
- Разборы возражений с решениями — «сохраню, покажу жене/партнёру»

### Триггеры репостов
- «Это же про меня!» — узнавание своей боли в точных деталях
- Злость на WB — «отправлю в наш Telegram-чат»
- Неожиданная цифра — «покажу другу который ещё на WB»

### Триггеры комментариев
- Вопрос в конце рилса к аудитории
- Провокационное заявление без полного ответа
- «Напиши в комментах свою маржу на WB» — UGC engagement

### Триггеры подписки
- Серийность: «в следующем рилсе покажу таблицу расходов»
- Обещание эксклюзива: «в закрытом чате разбираем кейсы»
- Авторитет без понтов: реальный дашборд продаж на экране

## Незакрытые ниши конкурентов (чем выделяться)

1. **Никто не показывает реальный P&L** — только красивые цифры оборота. Ты показываешь полную таблицу: комиссия + логистика + возвраты + хранение + реклама + штрафы = реальная чистая прибыль.

2. **Никто не разбирает юридику для россиян** — страх законности блокирует тысячи людей. Серия рилсов «законно из России» закрывает это белое пятно.

3. **Никто не делает сравнение «один товар — два маркетплейса»** с реальными скриншотами аналитики. Split screen с дашбордами — неопровержимо.

4. **Никто не говорит про выход из WB как про стратегию** — только про вход на Amazon. Переформулировка: «ты не начинаешь с нуля — ты переносишь навык».

5. **Страх потери ниши из-за китайцев** — не закрыт нигде. Рилс «почему китайцы на Amazon — сигнал денег, а не угроза» займёт эту нишу.

```
[0–1 сек] — ВИЗУАЛЬНЫЙ СТОППЕР (на экране: цифра, текст, лицо с реакцией)

[15–45 сек] — ФАКТЫ / ДОКАЗАТЕЛЬСТВО (экран, цифры, сравнение)
[45–55 сек] — ВЫВОД
[55–60 сек] — CTA (подпишись / напиши в комменты / сохрани)
```
