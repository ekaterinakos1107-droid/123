# Шаблон бренд-профиля

Скопируй этот текст в поле `brandProfile` ноды **Inputs** и заполни под свой бренд.
Чем конкретнее — тем стабильнее агент `Brand Stylist` держит стиль.

```
Brand: <название бренда>
Aesthetic: <общий стиль, напр. Scandinavian minimalism / bold streetwear / luxury editorial>
Palette: <2-4 основных цвета + 1 акцент, словами или HEX>
Mood: <настроение: calm / energetic / premium / playful ...>
Light: <тип света: soft natural daylight / hard studio / neon night ...>
Camera: <предпочтения по камере: slow push-in / handheld / static product shot ...>
Typography feel: <если в кадре текст: clean sans-serif / elegant serif ...>
Do: <что обязательно: чистый фон, крупный план продукта, мягкие тени ...>
Avoid: <чего избегать: clutter, saturated colors, glossy plastic, busy backgrounds ...>
```

## Пример (бренд NORD)

```
Brand: NORD
Aesthetic: Scandinavian minimalism
Palette: matte black, warm grey, soft cream, single muted sage accent
Mood: calm, premium, quiet confidence
Light: soft natural daylight, gentle shadows
Camera: slow push-in, static product shots
Do: clean uncluttered background, large product close-up, soft shadows
Avoid: bright saturated colors, clutter, busy backgrounds, glossy plastic looks
```
