# Seedance Content Factory (n8n + fal.ai)

Дешёвый мультиагентный «контент-завод» для генерации брендовых видео на **Seedance 2.0**.
Без подписок и без дорогих платформ — платишь только за сам рендер видео.

Конвейер: **идея → агент-промптер → агент бренд-стиля → Seedance 2.0 → готовый ролик**.
Весь «интеллект» (агенты) почти бесплатный; единственная реальная статья расходов — генерация видео.

---

## 1. Архитектура

```
[Start]
   │
[Config]          ← ключи API + настройки (модель, длина, формат)
   │
[Inputs]          ← твоя идея ролика + бренд-профиль (палитра, тон, do/don't)
   │
[Prompt Engineer] ← агент №1: превращает идею в кинематографичный промпт
   │
[Brand Stylist]   ← агент №2: переписывает промпт строго под стиль бренда
   │
[Seedance 2.0]    ← отправляет задачу в fal, ждёт рендер, забирает видео
   │
[Output]          ← videoUrl + финальный промпт
```

Агенты — это один и тот же дешёвый LLM с разными системными промптами (см. папку `agents/`).
«Обучается» не агент, а **бренд-профиль** — текстовое описание стиля, которое подмешивается в каждый ролик.

---

## 2. Что нужно (3 бесплатные регистрации)

| Сервис | Зачем | Стоимость |
|---|---|---|
| **n8n** | оркестратор (запускает конвейер) | бесплатно (self-host) |
| **fal.ai** | доступ к Seedance 2.0 API | pay-per-use, без подписки |
| **OpenRouter** | дешёвый LLM для агентов | копейки за вызов |

Ключи:
- fal.ai → Dashboard → **API Keys** → создать ключ (`FAL_KEY`).
- OpenRouter → **Keys** → создать ключ (`LLM_KEY`).

## 3. Установка n8n

**Вариант A — Docker (рекомендуется):**
```bash
docker volume create n8n_data
docker run -it --rm --name n8n -p 5678:5678 \
  -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
```

**Вариант B — npx (нужен Node.js 18+):**
```bash
npx n8n
```

Открой **http://localhost:5678** и создай локальный аккаунт.
(Не хочешь ставить — есть n8n Cloud, платный, но тот же импорт.)

---

## 4. Импорт и настройка

1. В n8n: меню (⋮ справа сверху) → **Import from File** → выбери `n8n-workflow.json`.
2. Открой ноду **Config** и впиши:
   - `LLM_KEY` — ключ OpenRouter
   - `FAL_KEY` — ключ fal.ai
   - (по желанию) `FAL_MODEL`, `resolution`, `duration`, `aspectRatio`
3. Открой ноду **Inputs**:
   - `idea` — что за ролик хочешь
   - `brandProfile` — стиль бренда (шаблон: `brand-profile.example.md`)
4. Нажми **Test workflow**. Через ~1–3 минуты в ноде **Output** появится `videoUrl` — ссылка на готовый MP4.

## 6. Как это работает (по нодам)

- **Config / Inputs** — обычные Set-ноды с ключами и входными данными.
- **Prompt Engineer / Brand Stylist** — HTTP-запросы в OpenRouter (chat completions). Ответ берётся из `choices[0].message.content`.
- **Seedance 2.0** — Code-нода:
  1. `POST https://queue.fal.run/<model>` — отправляет задачу, получает `request_id` + `status_url` + `response_url`;
  2. опрашивает `status_url` каждые 5 сек, пока `status === "COMPLETED"`;
  3. забирает результат с `response_url` → `video.url`.
- **Output** — финальная ссылка на видео и использованный промпт.

## 7. Как развивать дальше

- **QA-агент (главный апгрейд для «идеального ролика»).** После генерации добавь vision-агента, который смотрит кадр-превью и сверяет с брифом/брендом; если не ок — цикл перегенерации. Промпт готов: `agents/03-qa-reviewer.md`.
- **Консистентность бренда через картинку.** Вместо text-to-video используй `image-to-video` или `reference-to-video` (эндпоинты `bytedance/seedance-2.0/reference-to-video`) — подаёшь эталонные кадры/лого, и стиль держится стабильнее.
- **Batch-режим.** Замени `Start` на Google Sheets / Form trigger и гоняй пачку идей за раз.
- **Автопостинг.** Добавь в конец ноды публикации (YouTube/TikTok/Instagram) — n8n умеет это из коробки.
- **Дешевле рендер.** Переключись на BytePlus (см. раздел 5) или на self-host открытой модели (Wan 2.2 / LTX-Video) на арендной GPU.

---

## 8. Безопасность

Сейчас ключи лежат прямо в ноде `Config` — это ок для теста.
Для продакшена перенеси их в **n8n Credentials** (Header Auth) или в переменные окружения и ссылайся на них, чтобы ключи не попадали в экспорт воркфлоу.
