# Подключение postmypost по MCP

У postmypost есть официальный **MCP-сервер** — он позволяет мне напрямую
создавать публикации, загружать медиа, ставить в расписание и читать аналитику
в твоём рабочем пространстве postmypost.

- **Адрес сервера:** `https://mcp.postmypost.io/mcp` (удалённый, HTTP)
- **Что умеет:** создавать/редактировать публикации, отправлять на согласование,
  планировать и публиковать на все соцсети, **загружать и прикреплять медиа**,
  получать аналитику, управлять проектами и подключёнными аккаунтами.

Конфиг уже добавлен в репозиторий — файл `.mcp.json` в корне:

```json
{
  "mcpServers": {
    "postmypost": {
      "type": "http",
      "url": "https://mcp.postmypost.io/mcp"
    }
  }
}
```

## Как подключить (один раз)

1. В интерфейсе Claude открой **Settings → Connectors → Add custom connector**
   (в Claude Code: `claude mcp add --transport http postmypost https://mcp.postmypost.io/mcp`).
2. При первом обращении сервер попросит **авторизацию через браузер (OAuth)** —
   войдёшь в свой аккаунт postmypost и разрешишь доступ. Токен нигде вручную
   прописывать не нужно, секреты не хранятся в репозитории.
3. **Начни новую сессию** — MCP-инструменты подключаются на старте сессии, а не
   на середине. После переподключения у меня появятся инструменты `postmypost`.

## Что я смогу делать после подключения

Связать наш конвейер с реальной публикацией:

1. Беру план серии `plans/series-NN.csv` (фото → аккаунт).
2. Для каждой строки: загружаю фото в postmypost, создаю публикацию на нужный
   аккаунт Pinterest, ставлю в расписание на выбранное время.
3. Помечаю в `ledger.csv` статус `published` и записываю id публикации.

Уникальность «1 фото = 1 раз» по-прежнему держит наш реестр — postmypost о ней
не знает и знать не должен, это наша защита на входе.

## Если OAuth не подойдёт (запасной путь — токен)

Если в твоём тарифе используется API-токен вместо OAuth, его берут в настройках
аккаунта postmypost (раздел API). Тогда конфиг будет таким, а токен кладётся в
переменную окружения (не в репозиторий):

```json
{
  "mcpServers": {
    "postmypost": {
      "type": "http",
      "url": "https://mcp.postmypost.io/mcp",
      "headers": { "Authorization": "Bearer ${POSTMYPOST_TOKEN}" }
    }
  }
}
```

Документация: https://help.postmypost.io/docs/mcp/ и
https://help.postmypost.io/docs/api
